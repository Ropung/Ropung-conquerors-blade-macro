# Conqueror's Blade 매크로 개발 계획서
작성 기준: 2026-10-26
프로젝트 경로: C:\dev\conquerors-blade-macro

## 1. 목표
컨커러스 블레이드에서 탈것 상인 NPC를 통해 특정 마구를 구매하고, 구매한 마구만 분해하는 반복 작업을 Windows GUI 매크로로 구현한다.
사용자가 F9로 중지하거나 오류가 발생할 때까지 구매 → 분해 → 재구매를 반복한다.
게임 이용약관 및 안티치트 정책을 사전에 확인한다.

## 2. 개발 환경
- 운영체제: Windows 10/11
- 게임 해상도: 2560x1440
- 화면 모드: 전체 창 모드(Borderless Fullscreen)
- 언어: Python 3.12.x (64-bit)
- 주요 라이브러리: OpenCV, MSS, NumPy, PyAutoGUI, PySide6, keyboard
- 패키징: PyInstaller를 이용한 Windows EXE
- 실행 파일은 Python이 설치되지 않은 PC에서도 실행할 수 있도록 의존성을 포함한다.
- 개발 및 테스트는 Windows PowerShell에서 수행한다.

## 3. GUI 및 단축키
- 구매 수량 설정: 1~20개, 기본값 15개
- 설정을 config.json에 저장하여 재실행 시 유지
- 실행 상태와 로그를 GUI에 표시
- F6: 시작
- F7: 일시정지
- F8: 재개
- F9: 즉시 중지
- 일시정지 및 중지 신호는 각 작업 단계 사이에서 확인한다.
- 입력 자동화가 실행 중일 때 GUI가 멈추지 않도록 작업 스레드를 분리한다.

## 4. 자동화 작업 흐름
1. 시작 전 게임 창 활성화, 해상도, 필수 화면 인식 이미지 준비 상태를 확인한다.
2. 캐릭터가 탈것 상인 NPC 바로 앞에 있는 상태에서 F 키로 상호작용한다.
3. NPC 메뉴에서 '마구 상점'을 선택한다.
4. 상점 2페이지로 이동한다. 1페이지는 녹색 아이템 페이지이다.
5. 파란 등급 '버들잎 면갑'을 정확하게 식별해 선택한다.
6. 구매 버튼을 눌러 구매 수량 팝업을 연다.
7. 수량 입력란을 선택하고 Ctrl+A로 기존 값을 지운 뒤 설정 수량을 입력한다.
8. 구매 수량과 대상 아이템을 다시 검증한 후 구매를 확정한다.
9. ESC로 상점을 닫고 I 키로 인벤토리를 연다.
10. 인벤토리 왼쪽 세로 메뉴의 네 번째 분해 아이콘을 선택한다.
11. 인벤토리에서 구매 대상인 '버들잎 면갑'만 식별해 우클릭으로 분해 슬롯에 등록한다.
12. 분해 슬롯은 최대 15개이므로 15개 단위로 나누어 처리한다.
13. 분해 버튼을 누르고 완료를 기다린다. 아이템당 약 2초로 추정하되, 고정 시간만 믿지 않고 완료 화면을 인식한다.
14. '분해 완료, 확인하세요.' 팝업이 나타나면 '확인'을 누른다.
15. 남은 구매 대상 아이템이 있다면 같은 분해 패널에서 다음 묶음을 처리한다. 예: 20개 구매 시 15개 + 5개.
16. 모든 대상 아이템 분해가 끝나면 ESC로 인벤토리를 닫고 F 키로 NPC와 다시 상호작용한다.
17. F9 중지 또는 오류가 발생할 때까지 반복한다.

## 5. 수량 및 비용 참고
- 구매 수량: 1~20개
- 대상 아이템: 버들잎 면갑 (파란 등급)
- 구매 단가: 전쟁 코인 1,600
- 20개 구매 시: 전쟁 코인 32,000
- 15개 분해 등록 화면에서 확인한 분해 비용: 전쟁 코인 4,500
- 비용은 화면 인식으로 실제 값 확인 후 작업하며, 예상과 다르면 중지한다.
- 15개 분해는 약 30초, 5개 분해는 약 10초로 관찰되었으나 실제 완료 팝업을 기준으로 판단한다.

## 6. 이미지 인식 및 좌표 정책
- 게임 화면은 MSS로 캡처하고 OpenCV로 UI 요소를 탐지한다.
- NPC 상호작용, 상점 메뉴, 페이지 버튼, 대상 아이템, 구매 팝업, 수량 입력, 분해 아이콘, 분해 슬롯, 분해 버튼, 완료 팝업에 대한 템플릿 이미지를 준비한다.
- 제공된 스크린샷은 축소되어 보였으므로 과거에 추정한 좌표를 실제 2560x1440 좌표로 확정해서 사용하지 않는다.
- 게임 화면에서 직접 캡처한 이미지와 좌표를 기준으로 캘리브레이션한다.
- 화면 인식이 불확실하면 임의 클릭하지 않고 중지한다.
- 분해 대상은 반드시 '버들잎 면갑'으로 제한하여 기존 장비 및 다른 아이템을 보호한다.

## 7. 예외 처리 및 안전장치
- 게임 창이 활성화되지 않거나 해상도/화면 모드가 다르면 중지
- NPC, 마구 상점, 2페이지, 대상 아이템을 찾지 못하면 중지
- 구매 팝업에서 수량이 맞지 않거나 예상 구매 비용이 다르면 중지
- 분해 대상 아이템 식별에 실패하거나 다른 아이템이 섞이면 중지
- 분해 완료 팝업이 제한 시간 내 나타나지 않으면 중지
- 예상치 못한 팝업, 화면 전환, 입력 실패 시 로그를 남기고 중지
- 모든 클릭과 키 입력 전후에 상태를 검증하고 중지 요청을 확인
- 구매/분해와 같은 파괴적 동작은 실제 게임 화면 검증 후 활성화

## 9. 개발 단계
1단계: 프로젝트 생성, 가상환경, requirements.txt, config.json, GUI 기본 화면 구성
2단계: 게임 창 탐지, 화면 캡처, 템플릿 이미지 수집 및 인식 테스트
3단계: NPC 상호작용 → 상점 2페이지 → 대상 아이템 구매 자동화
4단계: 인벤토리 열기 → 대상 아이템 선택 → 15개 단위 분해 자동화
5단계: 상태 머신으로 구매/분해 흐름 연결, F6~F9 단축키 및 오류 처리
6단계: 1개 소량 테스트, 15개 테스트, 20개(15+5) 테스트, 장시간 반복 테스트
7단계: PyInstaller EXE 빌드 및 별도 Windows PC에서 실행 검증

## 10. 빌드 예시
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install opencv-python pyautogui mss numpy PySide6 keyboard pyinstaller
pyinstaller --onefile --windowed --name ConquerorsBladeMacro main.py

주의: 이미지 템플릿, 설정 파일 등 외부 리소스는 빌드 시 별도 포함 또는 실행 파일 옆 배치가 필요하다.

## 11. 완료 조건
- GUI에서 구매 수량 1~20개 설정 가능, 기본값 15개 유지
- F6 시작 / F7 일시정지 / F8 재개 / F9 중지 정상 동작
- 버들잎 면갑만 구매하고 버들잎 면갑만 분해
- 16~20개 구매 시 15개 + 나머지로 나누어 분해
- 완료 팝업 확인 후 다음 단계로 진행
- 예상치 못한 화면에서 무작위 클릭하지 않고 안전 중지
- 로그 확인 가능
- Python 미설치 Windows 환경에서 패키징된 EXE 실행 가능

## 12. Codex 작업 지침
- 이 문서를 구현 요구사항의 기준으로 사용한다.
- 실제 게임 스크린샷/템플릿이 없으면 임의 좌표를 확정하거나 자동화를 완성된 것으로 주장하지 않는다.
- 구현 순서는 GUI → 화면 인식 → 단일 구매 → 단일 분해 → 반복 제어 → 패키징으로 한다.
- 위험한 입력 작업은 기본적으로 비활성화하고, 테스트와 검증을 거쳐 단계적으로 활성화한다.
- 코드 변경 시 README와 실행 방법을 최신화한다.
